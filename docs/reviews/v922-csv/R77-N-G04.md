# R77-N-G04: Check the null direction of the sum measurement

S. 48, 49, 51: Zustandsdifferenz der beiden Beispiele ist (1/5,−1/5). Das Skalarprodukt mit (1,1) verschwindet, mit (1,−1) ist es 2/5. Eine anders gewichtete Probe, etwa (3/5,2/5), sieht 1/25 und ist ein anderes Messmodell. Die Aussage im Buch auf den Summensensor bezogen.
