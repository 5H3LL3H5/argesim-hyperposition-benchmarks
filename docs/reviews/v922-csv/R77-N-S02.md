# R77-N-S02: Verify four undefined relative string errors at zero reference norm

S. 341, 343. Für den mittigen Zupfpunkt bei t=25/6 s aus den 2376 Datensätzen genau die Gitter 65,129,251,501 selektiert. Die absoluten RMS-Fehler in Metern sind 1.0888893e-07, 3.02725304e-07, 4.15922893e-07, 3.27386643e-07. Alle vier sind endlich, und alle vier zugehörigen relativen Fehler sind im Export NaN, nicht fälschlich null.
