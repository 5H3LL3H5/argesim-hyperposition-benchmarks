# C02 implementation comparison

The implementation follows the official C02 definition for geometry,
processing times, finite B2 capacities, and routing.  Initial pallets are
scheduled as DEVS external events; simultaneous internal and external events
are processed deterministically.  A1 unloads only completed workpieces, and
the model reports the reference deadlock loading explicitly.

Selected deterministic results are compared with Table 2 of the independent
2011 SNE implementation (600 minutes total, 120 minutes warm-up):

| Pallets | Published throughput | This implementation | Published mean time (s) | This implementation (s) |
|---:|---:|---:|---:|---:|
| 10 | 959 | 1006 | 285 | 286.2 |
| 14 | 1439 | 1440 | 265 | 280.0 |
| 20 | 1439 | 1437 | 385 | 400.7 |
| 40 | 1437 | 1439 | 787 | 801.4 |
| 50--60 | deadlock | deadlock | -- | -- |

Source: [Benchmark C02 -- A Flexible Assembly System](https://www.sne-journal.org/fileadmin/user_upload_sne/SNE_Issues_OA/SNE_21_34/articles/sne.21.34.10101.bn02.OA.pdf).

These are independent reference checks, not values generated by the code
under test.  Because the non-deadlock metrics are close but not identical, the
catalog status remains **implemented**, not validated.
